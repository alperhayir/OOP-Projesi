# Task & Project Management System (OOP-Based)

This project is a simple task and project management system that allows users to create tasks, assign them to projects, and track their status.

The main objective of this project is to demonstrate Object-Oriented Programming (OOP) principles in a practical and structured way.

---

## 📌 Project Overview

The system enables users to:

- Create tasks
- Assign tasks to specific projects
- Set priority levels for tasks
- Define due dates for time-based tasks
- Mark tasks as completed
- List upcoming tasks
- Generate notifications for upcoming or completed tasks
- Export task data to a file

---

## 🎯 Purpose

This project was developed to apply and demonstrate key Object-Oriented Programming principles, including:

- Encapsulation
- Inheritance
- Polymorphism
- Interface usage

The system structure is designed to clearly reflect OOP architecture and modular design.

---

## 🛠 Features

- Task creation and management
- Project-based task organization
- Priority level assignment
- Deadline tracking
- Completion status monitoring
- Notification generation
- File export functionality

---

## 🧱 OOP Concepts Used

### 🔹 Encapsulation
Private fields with controlled access through methods.

### 🔹 Inheritance
Task types extend base classes where necessary.

### 🔹 Polymorphism
Common interfaces used to handle different task types dynamically.

### 🔹 Interface Usage
Interfaces implemented to standardize behaviors such as notifications or export functionality.
